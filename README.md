# JS Practice Tasks

School JavaScript practice tasks completed during JavaScript coursework.

This repository contains separate JavaScript practice task groups.

## Folders

- `basic_tasks` - beginner JavaScript tasks with inputs, conditions, loops, functions and DOM output.
- `animation_tasks` - DOM animation tasks with moving elements, keyboard events, mouse events and CSS animations.
- `game_tasks` - mini game tasks. This folder will be added later.

## Main topics

- HTML
- CSS
- JavaScript
- DOM manipulation
- addEventListener()
- Functions
- if / else
- loops
- Math.random()
- keyboard events
- mouse events
- CSS animations
