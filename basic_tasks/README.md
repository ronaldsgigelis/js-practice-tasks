# Basic JavaScript Tasks

This folder contains beginner JavaScript practice tasks.

The tasks focus on basic programming logic, DOM output, input handling, conditions, loops and simple calculations.

## Tasks

### Task 1 - Greeting with name

User enters a name and the program displays a greeting.

Example result:

```txt
Sveiks, Anna!
```

Main concepts:

- input value
- DOM output
- button click
- function

### Task 2 - Sum of two numbers

User enters two numbers and the program calculates their sum.

Main concepts:

- number input
- Number()
- arithmetic operations
- DOM output

### Task 3 - Even or odd number

User enters a number and the program checks if the number is even or odd.

Main concepts:

- if / else
- modulo operator `%`
- condition checking

### Task 4 - Age check

User enters age. If the age is 18 or greater, the program displays that the user is an adult. Otherwise, it displays that the user is not an adult.

Main concepts:

- comparison operators
- if / else
- DOM output

### Task 5 - Largest of two numbers

User enters two numbers and the program shows which number is larger.

Main concepts:

- comparison
- if / else if / else
- working with two input values

### Task 6 - Counting from 1 to 10

The program outputs numbers from 1 to 10 using a loop.

Main concepts:

- for loop
- text output
- string concatenation

### Task 7 - Multiplication table

User enters a number and the program displays its multiplication table from 1 to 10.

Main concepts:

- for loop
- multiplication
- innerHTML
- line breaks

### Task 8 - Random number

The program generates a random number from 1 to 10 and displays it on the page.

Main concepts:

- Math.random()
- Math.floor()
- random number generation
- DOM output

### Task 9 - Word length

User enters a word and the program displays how many letters are in the word.

Main concepts:

- string length
- input value
- DOM output

### Task 10 - Mini calculator

User enters two numbers and chooses an operation: `+`, `-`, `*`, `/`.

The program calculates and displays the result.

Main concepts:

- arithmetic operators
- select input
- if / else if
- division by zero check

## Main concepts covered

- HTML forms
- JavaScript variables
- DOM element selection
- input value reading
- textContent
- innerHTML
- Number()
- if / else
- loops
- functions
- Math.random()
- basic calculator logic

## How to run

Run the folder through a local PHP server, for example XAMPP:

```txt
http://localhost/js-practice-tasks/basic_tasks/
```

## Notes

PHP is used only to include separate task files into one page.

The main task logic is written in JavaScript.
